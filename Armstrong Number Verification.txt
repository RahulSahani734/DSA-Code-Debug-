Armstrong Number Verification (Extraction of Digits Approach)What is an Armstrong Number?An Armstrong Number (also known as a Narcissistic Number) is a number that is equal to the sum of its digits each raised to the power of the total number of digits ($k$).$$\text{Sum} = d_1^k + d_2^k + \dots + d_k^k$$3-Digit Example ($153$): Number of digits ($k$) = 3$$1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153 \quad (\text{Equal} \rightarrow \text{True})$$4-Digit Example ($1634$): Number of digits ($k$) = 4$$1^4 + 6^4 + 3^4 + 4^4 = 1 + 1296 + 81 + 256 = 1634 \quad (\text{Equal} \rightarrow \text{True})$$Core Logic: Digit Extraction & Power SumTo calculate the Armstrong sum dynamically without manually writing $d_1, d_2, \dots$:Find Number of Digits ($k$): Determine $k = \text{len}(\text{str}(n))$.Extract Last Digit: Use modulo 10 (digit = num % 10).Accumulate Power: Compute digit ** k and add it to total.Reduce Number: Integer divide by 10 (num = num // 10).Order Invariance: Processing digits right-to-left ($3^3 \rightarrow 5^3 \rightarrow 1^3$) gives the exact same result as left-to-right because addition is commutative.Dry Run Example ($n = 153, k = 3$):StepRemaining Number (num)Extracted Digit (num % 10)Calculation (digit ** 3)Accumulated Total (total)Initial153——01153$3^3 = 27$0 + 27 = 27215$5^3 = 125$27 + 125 = 152301$1^3 = 1$152 + 1 = 153Verification: Final accumulated total (153) equals original $n$ (153) $\rightarrow$ True.Python Code ImplementationPythondef is_armstrong(n: int) -> bool:
    # Preserve original n for final comparison
    num = n
    total = 0
    nod = len(str(n))  # Number of digits (k)
    
    while num > 0:
        last_digit = num % 10
        total += (last_digit ** nod)  # Raise to power k and accumulate
        num = num // 10
        
    return total == n
Complexity AnalysisTime Complexity: $O(\log_{10} n)$ — The while loop executes once for every digit in $n$.Space Complexity: $O(1)$ — Only a few primitive variables (num, total, nod, last_digit) are used, consuming constant memory.
