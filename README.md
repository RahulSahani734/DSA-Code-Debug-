# DSA Code & Debug

This repository is dedicated to practicing **Data Structures and Algorithms (DSA)** with a focus on writing clean code and debugging common issues.  
It will serve as a personal learning space to track progress, store solutions, and document insights.

---


## 📌 About
- Regular practice of DSA problems.
- Implementations in Python (and possibly other languages later).
- Debugging notes and explanations for tricky problems.
- Step-by-step solutions with complexity analysis.

---

## 📂 Structure
- `arrays/` → Problems related to arrays
- `linked-list/` → Linked List implementations
- `stack-queue/` → Stack and Queue problems
- `trees/` → Binary Trees, BST, etc.
- `graphs/` → Graph algorithms
- `sorting-searching/` → Sorting and searching techniques
- `misc/` → Miscellaneous problems and experiments
